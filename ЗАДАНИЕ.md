# Задание: менеджер задач «План на день»

## Цель проекта

Разработать удобный сайт для просмотра и ведения задач с исполнителями.
Задачи и пользователи загружаются из DummyJSON, а изменения сохраняются в браузере.
Весь сайт должен работать из одного файла `index.html` без сборки и установки библиотек.

Внешний вид: современное нежное оформление в голубой, кремовой и шоколадной палитре.
Интерфейс должен оставаться понятным на компьютере и на узком экране.

## Разделение ответственности для сдачи проекта

Это распределение частей проекта для объяснения и дальнейшей работы.

| Участница | Ответственность | Что объясняет на защите |
| --- | --- | --- |
| **Дауренкызы Акбота** | HTML, CSS и оформление интерфейса | Структуру страницы, палитру, адаптивную сетку, карточки команды и задач, фотографии, внешний вид профилей и форм |
| **Даулетбек Энхара** | JavaScript, API и данные | Загрузку задач и пользователей, связь по ID, фильтры, сортировку, создание и изменение задач, сохранение и обработку ошибок |

Акбота отвечает за то, как информация расположена и выглядит.
Энхара отвечает за то, как действия пользователя изменяют данные и обновляют страницу.
Форма задачи и окно профиля — общая точка взаимодействия этих частей: разметка и стили связаны с обработчиками JavaScript.
Обе участницы должны понимать полный пользовательский сценарий: создать задачу, назначить исполнителя и проверить результат.

## Функциональные требования

1. Загрузить весь список задач и пользователей из DummyJSON.
2. Показывать название, статус, ID и исполнителя каждой задачи.
3. Размещать маленький аватар и кликабельный `@username` под названием, включая длинные названия.
4. По нажатию на исполнителя открывать профиль с фотографией, доступными сведениями и его задачами.
5. В профиле показывать выполненные и невыполненные задачи и разрешать менять их.
6. Добавить поиск по названию, фильтр статуса и выпадающий список всех авторов.
7. Добавить сортировку названий от А до Я и от Я до А через API.
8. Открывать добавление задачи в модальном окне с названием, исполнителем и статусом.
9. Разрешать редактировать задачу, переключать статус и удалять после подтверждения.
10. Сохранять новые задачи и изменения после перезагрузки страницы.

## Структура и оформление

- Боковая навигация ведёт к рабочей области и команде.
- Вступительный блок и карточки команды используют общую палитру и оформление.
- Рабочая область содержит счётчики, обновление списка, фильтры и список задач.
- Состояния загрузки, пустой результат и ошибки отображаются отдельными сообщениями.
- Окна создания, редактирования и профиля используют нативный элемент `<dialog>`.
- У элементов формы есть подписи, у интерактивных элементов — видимый фокус.
- На небольших экранах сетка и элементы управления перестраиваются.
- Для пользователей с ограничением анимации учитывается `prefers-reduced-motion`.

## Работа с API

Базовый адрес: `https://dummyjson.com`.

| Действие | Запрос |
| --- | --- |
| Загрузить все задачи | `GET /todos?limit=0` |
| Загрузить пользователей | `GET /users?limit=0&select=...` |
| Сортировать по возрастанию | `GET /todos?limit=0&sortBy=todo&order=asc` |
| Сортировать по убыванию | `GET /todos?limit=0&sortBy=todo&order=desc` |
| Создать задачу для пользователя API | `POST /todos/add` |
| Изменить исходную задачу API | `PATCH /todos/{id}` |
| Удалить исходную задачу API | `DELETE /todos/{id}` |

Связь между задачей и человеком определяется полем `userId`, которое соответствует `id` пользователя.
Имена и аватары берутся из данных пользователя, а не из текста задачи.
Поиск по названию, выбор автора и фильтр статуса выполняются в загруженном списке и работают совместно.
Сортировка запрашивается у API; локально добавленные и изменённые задачи включаются в итоговый порядок.

DummyJSON имитирует создание, изменение и удаление: эти запросы не дают постоянной записи на сервере.
Поэтому сайт отдельно хранит изменения в браузере и накладывает их на свежий ответ API.
Повторное обновление списка не должно возвращать удалённую задачу или терять исправление.

## Профили участниц

Добавлены **Дауренкызы Акбота** (`@akbota`) и **Даулетбек Энхара** (`@enkhara`).
Это локальные профили с отдельными ID, которые не пересекаются с положительными ID DummyJSON.
Оба профиля доступны в карточках команды и первыми в списках исполнителей и авторов.
Их исходные фотографии встроены в HTML как данные изображения; отдельные JPG для запуска не нужны.
В профилях указаны только предоставленные сведения, без придуманных контактов и биографии.

Кнопка «Назначить задачу» открывает форму с уже выбранной участницей.
Задачи для локальных профилей создаются без отправки в DummyJSON.
Они поддерживают те же статусы, редактирование, удаление и сохранение, что и остальные задачи.

## Устройство JavaScript и сохранение

Состояние приложения разделяет исходные задачи API, новые локальные задачи, изменения и удалённые ID.
Единый итоговый список используется и в рабочей области, и в профилях.
После успешного действия интерфейс перерисовывает список, счётчики и открытый профиль.
Форма проверяет непустое название длиной до 180 символов и наличие выбранного исполнителя.
Во время отправки повторное сохранение блокируется; устаревшие ответы загрузки не заменяют актуальные данные.

Сохранение выполняется через `localStorage` по ключу `plan-on-day.tasks.v1`.
Восстанавливаются новые задачи, правки, статусы, назначения и отметки об удалении.
Кеш исходных задач и пользователей позволяет показать сохранённый список при сбое API.
Встроенные фотографии участниц не дублируются в хранилище.

Сохранённые данные проверяются по версии, структуре, типам и допустимым значениям.
Текст задачи отображается как текст, а не исполняемый HTML.
Если запись запрещена или место закончилось, задача остаётся в текущей вкладке и появляется предупреждение с повтором сохранения.
При замене повреждённого сохранения его исходная копия сначала записывается в `plan-on-day.tasks.v1.recovery`.
Сохранение относится к этому браузеру и адресу сайта; синхронизация между аккаунтами GitHub и устройствами не предусмотрена.
Очистка данных браузера удаляет сохранение, а приватная вкладка не подходит для долгого хранения.
