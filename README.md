# План на день

Небольшой менеджер задач на HTML, CSS и обычном JavaScript. Список загружается из DummyJSON Todos API. API имитирует изменение данных, поэтому создание, редактирование, отметки выполнения и удаление сохраняются только в памяти открытой страницы. После перезагрузки список снова загрузится с сервера, а локальные изменения сбросятся.

## Запуск

Откройте терминал в папке проекта и запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000>. Остановить сервер можно сочетанием `Ctrl+C` в терминале.

Для работы нужен интернет и установленный Python 3. Сборщик и дополнительные зависимости не используются.
